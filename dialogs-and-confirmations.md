# Dialogs and confirmations

---

## 18.1 Confirmation dialog

### When to use

Before irreversible or destructive actions (delete, remove, reset).

### Style

- Title: name the action, not the outcome. For example, "Delete connection" not "This is permanent."
- Body: one sentence stating what will happen and whether it can be undone.
- Primary CTA: matches the title verb. For example, "Delete."
- Secondary CTA: "Cancel."

### Do / Don't

| Do | Don't |
|---|---|
| Delete connection / This will remove the connection and cannot be undone. / Delete \| Cancel | Warning! Are you sure? This action is permanent. / Yes \| No |

---

## 18.2 Inline banner

### When to use

To display persistent warnings, errors, or informational messages within a page or form.

### Style

- State the issue and what the user should do. Keep to one to two sentences.
- Include a link or action if applicable.
