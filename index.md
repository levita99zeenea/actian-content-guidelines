## How to use these guidelines

Each section covers a specific UI component and follows a consistent structure:

- **When to use** — conditions and context for using this component
- **Style** — copy format, casing, punctuation, and length rules
- **Behavior** — how the component responds and what copy should reflect
- **Do / Don't** — side-by-side examples of correct and incorrect usage

Use the sidebar to navigate to any section, or search by keyword using the search bar above.
