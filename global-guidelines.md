# Global guidelines

Actian Data Intelligence speaks to data professionals: engineers, analysts, and catalog administrators. The voice is direct, precise, and professional without being formal or stiff.

---

## Voice and tone

**When to use:** Apply these guidelines to all UI copy, including labels, tooltips, empty states, error messages, and notifications.

### Style

- Use active voice. "Export the dataset" not "The dataset can be exported."
- Use present tense. "Saves automatically" not "Will save automatically."
- Use sentence case for all UI text, including headings and button labels.
- Do not use exclamation points except in genuine success states.
- Do not use "please" or "sorry" - they add length without value.

### Do / Don't

| Do | Don't |
|---|---|
| Export the dataset | The dataset will be exported |
| Something went wrong | We're sorry, something went wrong |
| Log in | Sign in / Signin |
{: .do-dont-table}

## Words to avoid

The following terms are banned from Actian product UI. Use the recommended alternatives.

| Term to avoid | Use instead | Reason |
|---|---|---|
| Please / Sorry | Omit or rephrase | Unnecessary filler; adds length without value |
| We / Us (referring to Actian) | "Actian" or omit | Use the product or company name; avoid first-person company voice in UI |
| Execute / Abort | Run / Cancel or Stop | Technical jargon; inconsistent with platform conventions |
| Master / Slave | Primary / Secondary | Exclusionary terminology |
| Blacklist / Whitelist | Deny list / Allow list | Exclusionary terminology |
| Press / Type (as verbs) | Click / Enter or Provide | Assumes physical input; not accessible |
| CTA | Button or link | Developer speak; not user-facing |
| Caution / Danger | Remember: / Note: | Alarming labels; use plain callout language instead |
| Disabled | Blocked / Off | Ambiguous; describe the actual state instead |
| Ensure | Verify | "Ensure" implies the user can guarantee outcomes |
| Agnostic | Independent | Jargon; unclear to non-technical users |
| Sign in / Signin | Log in | Actian platform standard is "log in" |
| Action on | Omit; use a direct verb | Vague and awkward phrasing |
